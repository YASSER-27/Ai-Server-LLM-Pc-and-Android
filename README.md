# AI Server: LLM for PC and Android
A simple setup to run Local Large Language Models (LLMs) on your PC and access them via your Android device.
# Getting Started
## PC Setup:
Download and install Ollama.
Download your preferred model (e.g., llama3 or mistral).
Run main.py OR navigate to the app windows folder and run Start Engines.exe.
## Android Setup:
Install LLM Server.apk on your phone.
Open the app and enter your PC's IP Address.
#Enjoy!
The Android source code is included in the repository if you wish to customize the app.
